    `edge.hl-note`, `node.text`.

## Key Insights
- Strata teaching that landed: layers exist ONLY because of "not"; no negation = one
  phase. Election analogy (can't name non-voters until polls close). Nesting shape:
  strata(outer) > rounds(middle) > rules > blank-fills(inner); freeze between strata.
- Monoid = (combine op, identity); the identity is a different "zero" per monoid (1 for x,
  "" for concat). Commutative needed to fold a SET. Semilattice (idempotent) = safe in
  recursion; sum (non-idempotent, can go down with negatives) must be stratified.
- Adjoint/Galois = best-paired opposite translations locked by an iff; abstract
  interpretation is the order-theory "Laplace move" (go to easy domain, solve, return).
- Renderer: edges already had notes in the model; the win was rendering them. Canvas
  labels are plain text (no md) -> strip markers for text cards; tooltips/detail can be
  rich HTML.
- Animation constancy = object constancy: lay out once, fix the camera, tween opacity;
  do NOT refit per step.
