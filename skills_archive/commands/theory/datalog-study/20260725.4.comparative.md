# Comparative: Datafun / Flix / Souffle / sprefa-dl

Reads the three system chapters ([datafun](20260725.1.datafun.md),
[flix](20260725.2.flix.md), [souffle](20260725.3.souffle.md)) against each other
and against what `v6/dl` actually does. Foundations for the vocabulary are in the
[math prereqs](20260725.0.datafun-math-prereqs.md).

## One-line identities

| system | identity |
|---|---|
| **Datafun** | monotonicity promoted from a syntactic ban to a **type**; Datalog's fixpoint core embedded in higher-order FP; pure and total. |
| **Flix** | Datalog constraint sets as **first-class values** in a full ML-family JVM language, with true lattice-valued facts. |
| **Souffle** | Datalog **compiled to parallel C++** for batch whole-program static analysis; the throughput ceiling. |
| **sprefa-dl** | reactive **Datalog-over-code**: incremental retraction plus an effect edge, lowered to a SQL semi-naive fixpoint. |

## The axes

| axis | Datafun | Flix | Souffle | sprefa-dl |
|---|---|---|---|---|
| **host paradigm** | higher-order FP, Datalog is the fixpoint core | general FP, Datalog is one embedded feature | standalone Datalog, compiles out | Datalog-first, SQL is the only host |
| **monotonicity** | in the **type system** (monotone arrow / `□` modality), checked | lattice type-classes + stratification; functions general | syntactic (stratification), no type-level monotonicity | operational, post-hoc (`rulegraph.ts` SCC) + hand guards |
| **negation** | `□` + `fix` side-condition = a type theorem | compiler stratifiability check during typecheck | stratification pass, pre-eval | post-hoc graph check, `negAdj` same-SCC throws `NonStratifiableError` |
| **lattices** | semilattice types, no infinite ascending chains; `fix` at a semilattice | full `JoinLattice`: true cross-row lub (`Neg ⊔ Pos = Top`) | none general; aggregates + subsumption approximate | `MaxBy`/`MinBy` = row-**selection** only (v5), no cross-row join; **not yet ported to v6** |
| **higher-order / compose** | full (functions as values) | first-class constraint values, `<+>` compose, functions build rule-sets | components (`.comp`), no first-class constraint values | none; a `.dl` is a static program |
| **recursion eval** | `fix` from `⊥`; seminaive = derivative (`semifix`), general `Derive` | semi-naive solver on JVM | compiled semi-naive + **magic sets** (static adornment) | SQL semi-naive delta loop (`lowerSql` `_dl_delta_`), hand-differentiated |
| **incremental / retraction** | none at runtime (2020 result is a program transform) | batch solve, no reactive retraction | batch, no live retraction | **delta plane (±weight), DRed retraction, re-tick on EDB change** |
| **effects / outside world** | none (pure `fix`) | algebraic effect system exists, but Datalog part is pure | `.input`/`.output` I/O directives only | the **host edge** (`?`/`!` sigils, rxjs); the whole effect theory-craft |
| **perf posture** | research prototype (correctness) | JVM, practical | compiled parallel C++, fastest | interpreted SQL fixpoint: interactive + incremental, lower ceiling than Souffle |

## Where each dl decision comes from

- **Stratification** is the one thing all four share, enforced at four different
  points: Datafun as a `fix` typing side-condition, Flix inside typecheck, Souffle
  as a pre-eval pass, sprefa as a post-hoc SCC property. The mechanism is identical
  (topological sort of the condensed predicate-dependency graph; negation edges
  forced backward across strata). See the React connection in the study notes:
  it is the compile-time proof React lacks, which is why an unstratified setState
  loop only trips a runtime counter.
- **The monotone/non-monotone boundary.** Datafun draws it cleanest (per-variable,
  `□`). sprefa draws the same line coarsely, per-rel: `RelDecl.origin` source vs
  derived, and the refusal to head one rel with both a source and a derived rule.
  `□A` ("finished changing before you read it") is the formal shape of sprefa's
  "negated rel is a finished table by the time `NOT EXISTS` runs."
- **Seminaive.** Datafun's `semifix` derivative is the general theorem; sprefa's
  `evalRecursiveStratum` is its first-order special case, hand-differentiated
  because every rule body is a conjunctive join. Souffle compiles the same
  recurrence to C++.
- **Magic sets is the near-miss.** Souffle's adornment-based magic sets statically
  specialize a recursive rule set to a query's bound constants. sprefa's
  `__req`/`__resp` demand rewrite *rhymes* with it but is scoped to effectful
  host-call demand (async probes with witness columns), not a static specialization
  of EDB-recursive rules. Named as a parallel, not an equivalence.
- **Lattices are the honest gap.** Flix's `JoinLattice` computes a value neither
  input had; sprefa's `MaxBy`/`MinBy` picks a whole winning row and explicitly does
  "no Galois cross-row mixing." Flix is the design reference for that decision if dl
  ever grows real lattice facts; it has not, and v6 has not even ported the v5
  row-selection version.

## What sprefa alone has, and what it alone lacks

**Alone has:** live retraction (the delta/weight plane, DRed) and an effect edge to
the outside world (`?`/`!` on rxjs). None of Datafun, Flix, or Souffle models a
fact **leaving** the fixpoint because its source changed, and none models a host
effect fired from inside the derivation. This is the reactive-over-code thesis, and
it is genuinely outside all three references.

**Alone lacks:** a monotonicity **type system** (Datafun), true lattice facts and
first-class composable rule-sets (Flix), and a compiled-C++ throughput path
(Souffle). Each is a real gap, not a rough edge, and each has a clear owner in the
reference above if it is ever pursued.

## The map in one sentence

Datafun is the **theory** of why sprefa's stratification and seminaive are correct;
Flix is the **richer relational model** (lattices, first-class constraints) sprefa
has not reached; Souffle is the **performance ceiling** sprefa trades away for
interactivity; and sprefa's own contribution, live retraction plus an effect edge,
is the axis none of the three occupies.
