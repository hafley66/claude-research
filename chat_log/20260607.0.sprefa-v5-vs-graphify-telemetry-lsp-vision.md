## Solution/Approach
- NOT Glean: fixed-language Thrift+RocksDB server, forecloses language design +
  embeddability. Reference only. Glean DOES allow custom facts (v5 currently does
  not, beyond matchers). Glean already has rich types (Angle: records/sums/preds).
  Glean limits: stacked-DB visibility cost, ownership memory (Elias-Fano ~7%),
  manual query ordering (no optimizer), derive-on-demand expensive.
- UNIFYING PRINCIPLE (pinned in STUDY.md): retraction lives at source-adapter
  boundaries via snapshot-diff; engine stays sync fixpoint scoped by affected_derived
  (engine.rs:342). Supports LSP-push + external mutable sources WITHOUT rebuilding
  v4's delta engine. Only a perf threshold ever forces real IVM.
- Programmable LSP: each method = typed relation + seeding convention (diag is the
  prototype). PULL=point query no state; PUSH-replace=resend (free retraction via
  replace-by-URI); PUSH-refresh=affected-set then re-pull. Depends on Track B types.
  Reclaim ONE v4 idea: dirty-buffer overlay (dirty_source.rs) for unsaved-buffer
  completion (currently save-driven, lsp.rs:1-3).
- KEY INSIGHT: SCIP monikers = stable symbol identity across revs. Powers BOTH
  accurate resolution (vs tree-sitter lexical guess) AND temporal path-analysis.
  Two-tier: lexical spine always present + resolved SCIP overlay when indexer ran.
- tsc-go / TS7 Beta (2026-04-21, ~10x) raises perf ceiling -> "full recompute per
  tick" affordable, validates sync bet. Embed API not until 7.1; ingest via tsgo LSP.
- AI loudspeaker: ai_rev from Co-Authored-By trailer x blame -> ai_line; diag on
  protected-zone overlap; surfaced via --lsp, --check, and a PreToolUse HARD gate
  (refuses the agent edit live). Fixes old "AI edited do-not-touch files" pain.

## Key Insights
- graphify's every bug traces to node-identity = casefold(slug(name)); v5/v4
  content-addressing makes that class impossible.
- All mutable fact sources (editor buffer, shell, browser, PR, ticket) normalize to
  located(coord, t) and join against module_edge/type_edge. Retraction = snapshot-diff
  at each adapter boundary, never engine-internal.
- LSP protocol is invalidate-and-recompute, not delta-streaming, so programmable LSP
  does NOT require v4's IVM engine.
- SCIP identity is the single enabler for "resolved facts" AND "temporal evolution."
- Service workers see only fetch (no DOM); VS Code sandboxes workbench DOM. The
  semantic event API (or LSP) is the right layer for editor/browser telemetry, not DOM.
- Morale: in this session the careful thing (v5) was correct and the hyped thing
  (graphify) was hollow; the value/capability doesn't depreciate as models improve.
