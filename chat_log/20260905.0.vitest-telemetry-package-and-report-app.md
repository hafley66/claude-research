## Problem/Context
User rejected Perfetto, Jaeger, catapult trace2html, markdown as unreadable; wants one click, hierarchical marbles by time containment with detach glyph (child outlives parent), lively hover, process tree showing how `pnpm test` reached each shard, everything resizable with CSS-owned proportions, minimal JS, React+rxjs+lodash as the sane default, beautiful code, e2e tests. Vitest sharding is per (project,file) spec by sha1(path) contiguous slice, not per project. `vitest.project` attr is "browser (chromium)" vs junit "browser": normalized to project + instance.

## Solution/Approach
- Plugin `telemetry()` injects define `__TELEMETRY__`, setupFile (realm-detecting), receiver globalSetup, otel sdk paths; disables otel + receiver when argv has `--merge-reports`.
- Containment nesting in `timeline.ts` (`id`, `parentId`, `detachedAt`, tie rule `end <= next.start` = sibling; BigInt nanos parse).
- Native primitives everywhere (popover, anchor positioning, details, light-dark, @layer, nesting), React only as renderer.
- Resize: CSS variables for tracks, drag = transform only, commit once on release (perf lab result).

## Key Insights
- Vitest 4 propagates span context main->worker (worker.start -> runtime.setup) and worker->main (module.inline -> module.transform); browser page loses async context after first await (orphan roots); TRACEPARENT env honored in `traces.*.js:94`.
- Chromium subgrid bug: `<details>` with `grid-template-columns: subgrid` mis-sizes the non-summary child; do not chain subgrid through details.
- Self-referencing `--depth: calc(var(--depth)+1)` is invalid at computed time; seed depth inline.
- `<details>` innerHTML re-render loop and first-paint `startViewTransition` hang: both hit and fixed.
- Native `Observable` in Chromium 151 (`when()`, map/filter/switchMap/takeUntil...), no Subject/shareReplay; user does not want it.
- Hafley stack differentiators: typed path template shared by URL/DOM ids/events; relative DOM routing via `data-route`; duplex Storage trait.
