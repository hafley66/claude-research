## Problem/Context
Research phase (haiku lanes, web search capped at 200) established: vitest captures `console.*` only, so loggers writing to stdout (pino, winston, debug on node, tslog v5 node) lose per-test attribution; LogTape + consola are the console-based isomorphic options; LogTape has the category tree. Vitest 4.0.11 core has `experimental.openTelemetry` (sdkPath/browserSdkPath), spans `vitest.test.runner.{run.test,test.beforeEach,test.callback,test.afterEach,test.cleanup,suite.beforeAll,...}` with attrs `vitest.test.{id,name,mode,timeout}`, `code.file.path`, status ERROR + exception event on failure. Browser-side vitest spans are flat siblings under `vitest.browser.tester.run` (no async context in page). Blob reporter carries `task.logs`, so `--merge-reports` replays console logs. No free v3 plugin does logging+tracing; v4 core otel + LogTape is the turnkey path. Testops SaaS with vitest ingestion: Datadog, Trunk (junit), Buildkite, Launchable, Codecov, Knapsack, Mergify, ReportPortal, Allure. Self-hosted one-UI OTLP backends: grafana/otel-lgtm, SigNoz, HyperDX, OpenObserve, Uptrace; Jaeger traces only. GHA fan-in: matrix `--shard` + `upload-artifact` per shard + `download-artifact merge-multiple` + `--merge-reports`; collector `githubreceiver` for workflow spans; vitest reads `TRACEPARENT`.

## Solution/Approach
- `Logger(import.meta.url)` in `src/log.ts`: category = `['lab', ...repo-relative path]` using `__ROOT__` define; one root config entry covers all files; per-folder overrides optional.
- `lab/plugin.ts` Vite plugin `config()` returns `define` (`__ROOT__`, `__OTLP__`, `__SHARD__`), `optimizeDeps.include` for otel/logtape/debug, `test.globalSetup` receiver, `test.experimental.openTelemetry` paths. Import it with `.ts` extension or vitest inlines it and duplicates modules ("failed to find the current suite").
- `setup.shared.ts` exports `baseConfig()` + `installLifecycle()`; each realm configures once (`setup.node.ts` adds stream file sink + AsyncLocalStorage; `setup.browser.ts` plain). `configure({reset:true})` twice disposes sinks and shuts down the LoggerProvider.
- `@logtape/otel` uses `import(variable)` for its exporter, unresolvable in the page; pass a static `LoggerProvider` (`SimpleLogRecordProcessor({ exporter })`) built in setup.
- `@logtape/testing-vitest` wrapper sets `parentSinks:"override"` inside test bodies (phase 1); phase 2 uses `createTest({mode:'always', sink: fanout})`, flush happens after callback so assert in `onTestFinished`. Browser project uses plain vitest `test` (autoload needs node:async_hooks).
- debug.js bridge overrides `debug.log`; `debug.enable()` on node writes back `process.env.DEBUG`, so prepend existing value or Playwright's `pw:api` goes silent.
- Playwright: no OTel; `DEBUG=pw:api DEBUG_FILE=...` works for both provider (main process) and e2e worker but truncates per process; `context.tracing` zips + `browser.trace` annotations work.
- Receiver (`lab/receiver.ts`) is a globalSetup OTLP/HTTP JSON sink with CORS; singleton guard since globalSetup runs per project; `--merge-reports` needs `--experimental.openTelemetry.enabled=false`.
- `lab/timeline.mjs` merges spans/logs/metrics/pw:api/junit into `timeline.jsonl` (fields: kind, realm, service, shard, project, suitePath, file, test, testId, traceId, spanId, depth, name/message, durationMs, status, error, level, category[], attrs) and `by-test.md` (grouped `## file` > `### suite > test`, indented by time containment, orphan browser events attributed by realm+file+time window).
- `lab/perfetto.mjs` -> Chrome trace format `out/trace.json`: process=`shard N · project`, thread=`realm · file`, slice `run.test <name>`, logs/pw/verdicts as instants, metrics counters; 38 benign overlap spills.
- Allure: reporter in config, `pnpm allure` = `allure awesome ... --single-file --history-path allure-history.jsonl`; single html opens from file://; History tab works across runs; lacks logs/spans/project/realm; `ALLURE_LABEL_shard` env added for shard label.

## Key Insights
- Vitest 4 browser otel spans are flat; nest by time containment.
- LogTape reset disposes sinks; build provider once per realm.
- Vitest config imports without extension get inlined and duplicate module state.
- Perfetto ships `perfetto-ui.zip` prebuilt static UI; needs COOP/COEP headers; no single-file build.
- Node passing-test console output is captured (junit system-out) but the terminal reporter hides it; `--disableConsoleIntercept` shows it (unresolved why).
- Prod-built app loses source path in `import.meta.url` (category becomes chunk name).
