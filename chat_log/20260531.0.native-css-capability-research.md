## Key Insights
- Popover API = Baseline Widely. Anchor positioning = Baseline Newly (Jan 2026): Chrome 125,
  Safari 26.0, Firefox 147 (VERIFIED). Polyfill @oddbird/css-anchor-positioning 0.9.0 (no
  position-try-order, no position-visibility, breaks on dynamically added anchors, main-thread).
  Native loses to Floating UI on continuous shift(), arrow middleware, virtual/cursor elements.
- anchor() can reference DIFFERENT named anchors per inset property -> a single box stretches between
  two nodes. The node-editor edge trick. CONFIRMED in the wild: Cory Rylan flow charts, Roland Franke
  connectors, kizu.dev experiments. Honest ceiling: CSS owns edge layout + node chrome; JS still owns
  routing, auto-layout, pan/zoom, drag. Nobody markets it as React Flow / rete.js replacement.
- Node-editor gotchas: abs-positioned edge can't anchor to abs-positioned SIBLING nodes (wrap nodes
  in relative containers); Safari vs Chrome differ on containing-block overflow; [popover]{margin:unset}
  needed; no ::tether pseudo (arrowheads via ::before/::after).
- Scroll-driven animations turbulence = @scroll-timeline at-rule REMOVED, replaced by
  scroll-timeline/view-timeline props + scroll()/view() + animation-range. Chrome 115, Safari 26.0,
  Firefox flag-only (Nightly default 136+). flackr polyfill is main-thread. #1 gotcha: named timeline
  only visible to descendants -> needs timeline-scope on a common ancestor (the TOC trick).
- Docs least-JS stack: reading-progress (scroll()), animated TOC (timeline-scope), <details name>
  exclusive accordion (SAFE) + ::details-content (SAFE) but height slide CHROMIUM-only
  (interpolate-size, fallback max-height), cross-doc @view-transition (Chrome 126/Safari 18.2, FF
  hard-navigates = safe degrade; 4s timeout + object-fit gotchas).
- FS explorer stack: :has() chevrons/ancestor-highlight (SAFE), subgrid columns (SAFE), interpolate-size
  expand (CHROMIUM), scroll-state stuck/scrollable shadows+more-below (CHROMIUM, Chrome 133+), inert
  split-pane + <dialog> rename (SAFE).
- Invoker commands (command/commandfor) = the one genuinely cross-engine NEW capability: Baseline
  Newly since 2025-12-12 (Chrome 135, FF 144, Safari 26.2). Custom commands start with -- and fire
  CommandEvent; superset of popovertarget.
- "CSS as a language" (if() Ch137, @function Ch139, typed attr() Ch133, sibling-index/count Ch138)
  is Chromium-only. if() and @function are RISKIEST: no Mozilla/WebKit position, not in Interop 2026.
- shape() and contrast-color() GRADUATED to Baseline Newly (verified 2026-05) -- both stronger than
  the original briefs claimed.
- Cross-engine tiers -- SAFE: anchor positioning, scroll-driven anim, cross-doc view transitions,
  field-sizing, sibling-index/count(2 of 3), typed attr(), customizable select, shape(), contrast-color().
  CONTESTED: interpolate-size (WebKit silent), corner-shape (Mozilla silent). RISKY/no-signal: if(),
  @function, scroll-state CQ, CSS carousel, reading-flow, caret-animation. Interop 2026 is the
  commitment device; only 4 of 15 researched features are formal 2026 focus areas.
