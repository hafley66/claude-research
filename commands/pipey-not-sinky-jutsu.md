## Reference quotes

- BigQuery pipe syntax: "Pipe operators can be applied in any order, any number of times." Each operator takes a table and returns a table. Aggregate-then-filter is legal:
  ```sql
  FROM mydataset.Produce
  |> AGGREGATE SUM(sales) AS total, COUNT(*) AS num_records
     GROUP BY item, category
  |> WHERE total > 5;
  ```
- jq manual on `|`: "The | operator combines two filters by feeding the output(s) of the one on the left into the input of the one on the right."
- jq manual on `empty`: "`empty` returns no results. None at all. Not even `null`." Used inline: `[1, 2, empty, 3]` evaluates to `[1, 2, 3]`. zero-output is not a terminator, its just a filter that produced nothing.
- Unix pipeline (Wikipedia): "A pipeline is a set of processes chained together by their standard streams, so that the output text of each process (stdout) is passed directly as input (stdin) to the next one." uniform byte-stream interface is the whole reason no command is "terminal".
- `tee` is the proof that side-effecting ops don't have to be sinks: it writes to a file *and* passes stdin through to stdout. side effect + pass-through is one op, not two roles.
- McIlroy: "Write programs that do one thing and do it well. Write programs to work together. Write programs to handle text streams, because that is a universal interface."
- KQL (Microsoft Learn): "Each operator accepts a tabular dataset 'from the pipe', and other inputs including more tabular datasets from the body of the operator, then emits a tabular dataset to the next operator that follows." `summarize`, `project`, `where` all share that contract; none is positional.
- Differential dataflow: "instead of using semi-naive evaluation and DRED, one can just describe the evaluation process as a dataflow, and have both additions and retractions handled in the same way". symmetric handling of add/retract = no privileged terminal operator.
- rxjs / LINQ as the anti-pattern: rxjs splits operators into "creation" vs "pipeable", and a `Subscriber` is "the sink ... with a destination of type SafeSubscriber". the cost of that split is exactly the compromise we're trying to avoid: the consumer end is a different kind of thing than the middle, so you cant freely re-pipe past it.
